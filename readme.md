## 🎯 What is This?

**LEMP Stack Manager** is an interactive, colorful, and user-friendly bash script that makes managing your **L**inux, **E**ngine-X (Nginx), **M**ariaDB, and **P**HP stack an absolute breeze! 

No more googling commands. No more typos. Just pure, beautiful simplicity. ✨

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Beautiful TUI** | Colorful, easy-to-navigate terminal interface |
| 📦 **One-Click Installs** | Install PHP 8.3, Nginx, MariaDB with a single keypress |
| 🔧 **Service Management** | Start, stop, restart, enable, disable services easily |
| 📋 **Live Logging** | Real-time log viewer built right into the interface |
| 🛡️ **Safe Execution** | Confirmation prompts before destructive actions |
| 🚀 **Non-Interactive** | No apt prompts interrupting your flow |
| ✅ **Error Handling** | Clear error messages and status reporting |

## 🚀 Installation

### Quick Start (One-Liner)

```bash
curl -fsSL https://raw.githubusercontent.com/harimau99/lemp-manager/main/lemp-menu.sh -o lemp-menu.sh && chmod +x lemp-menu.sh && sudo ./lemp-menu.sh
```
### Manual Installation

```
# 1. Clone or download the script
git clone https://github.com/yourusername/lemp-manager.git
cd lemp-manager

# 2. Make it executable
chmod +x lemp-menu.sh

# 3. Run with sudo
sudo ./lemp-menu.sh

```
